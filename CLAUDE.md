# Advanced Privacy Dashboard

Real-time macOS privacy monitoring, network analysis, threat detection, and security management app.

## Stack
Swift, SwiftUI, Swift Charts, SQLite3, WidgetKit, XcodeGen, Swift Package Manager

## Commands
- `swift build` -- build via SPM (no widget extension)
- `swift test` -- run unit tests
- `xcodegen generate` -- regenerate Xcode project from project.yml
- `open AdvancedPrivacyDashboard.xcodeproj` -- open in Xcode (recommended for full build with widget)
